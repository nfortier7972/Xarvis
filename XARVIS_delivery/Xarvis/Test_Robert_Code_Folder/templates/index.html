Tip
About these images. They have slight display enhancements: colour from two wavelengths, sharpening and upscaling (the measurements use the original pixels). They can show artefacts such as detector ghosts, cosmic-ray hits, edge effects and halos around bright stars. The automatic detection (the sky map, NEW objects and tracking) can make mistakes, so check a result before drawing conclusions from it.
